# Genshin Browser

一个专门为 B 站原神攻略视频设计的 Windows 浮窗浏览器，基于 `WPF + WebView2`。

## ✨ 功能

### 浮窗透明
- **透明度可调**：10%–100%，自由调节窗口透明度
- **游戏叠加使用**：半透明浮窗置于游戏上层，边玩边看
- **鼠标穿透（可选，默认关）**：开启后浮窗模式下点击直接落到下层游戏；浮窗内无法点击和拖动，按 `F8` 回浏览模式调整
- **穿透时的控制按钮（可选，默认关）**：鼠标穿透右边的子选项。开启后浮窗标题栏常驻，标题换成倒退 5 秒 / 播放暂停 / 快进 5 秒三个按钮，整条标题栏可点（也能拖动浮窗），视频区照旧穿透；适合触屏、远程串流时控制视频，点按不会让游戏失去焦点

### 窗口模式
- **浮窗**：窗口置顶，适合叠在游戏上观看；标题栏默认自动隐藏（鼠标移到窗口顶部时出现），可在设置里关掉「隐藏标题栏」改成常驻
- **浏览**：可拖动、调整大小，配合控制台找片与设置
- **快捷键切换**：`F8` 一键切换 浏览 ⇄ 浮窗
- **临时隐藏**：`F7` 隐藏/恢复窗口，视频继续播放（保留声音），任务栏图标可点击恢复
- **浮窗提示**：浮窗模式下按热键播放/暂停、快进/倒退时，主窗底部显示短提示；页面没有视频或自动播放被拦截也会提示
- **视频铺满**：标题栏按钮让视频铺满窗口（不占满屏幕；B 站用播放器自己的全屏，弹幕与控制栏保留），再点或按 `Esc` 退出

### 自定义按键
- **五组热键**：浏览 ⇄ 浮窗、播放/暂停、隐藏窗口、倒退 5 秒、快进 5 秒，均可在「按键绑定」面板中修改
- **生效范围三档**：黑名单外（默认，在浏览器、聊天工具、编辑器等已知非游戏软件中不触发）/ 全部应用 / 关闭
- **远程按键（可选，默认关）**：开启后 UU 远程、Parsec 等远程控制软件和按键映射工具发出的按键也能触发热键（这类按键是软件模拟的，默认只认键盘上实际按下的键）
- **防误触**：在页面或控制台输入框中打字时不触发播放与快进快退

### 浏览与记录
- **登录态保留**：Cookie、自动填充和已保存密码不会被缓存清理影响；缓存超过阈值时自动回收（只清可再生缓存，不动站点本地设置，如 B 站播放器音量、弹幕设置）
- **收藏夹**：一键收藏，支持搜索
- **浏览历史**：自动记录访问历史，支持搜索
- **地址栏联想**：输入时从收藏和浏览记录里给出候选（收藏在前），`↑` `↓` 选择、`Enter` 打开、`Esc` 关闭
- **智能恢复**：记住上次浏览的页面、窗口位置和大小
- **记住视频进度**：B 站、YouTube 视频页播放中每 10 秒记一次进度，退出前再记一次；下次启动、浏览器崩溃恢复、页面卡死重新加载时用 `t=` 接着放（B 站有时自己不保存进度）；开头 10 秒、最后 15 秒不记
- **配置导入 / 导出**：设置面板右上角「管理配置」里导入 / 导出，窗口大小与位置、各项设置、快捷键、收藏、浏览记录和当前页面存成一个 JSON 文件，可在另一台电脑导入（不含登录状态）；导入前自动备份当前配置，收藏 / 浏览记录或窗口大小位置与现在不同时先问你用哪一套
- **数据文件保护**：设置、收藏、浏览记录、下载记录读不出来（内容损坏等）时，原文件改名为 `名称.broken-时间.json` 留在数据目录里，不会被之后的保存覆盖；文件被其它程序占用、改名也失败时，本次运行不写它；启动后提示一次
- **外部程序**：网页要打开外部程序（`xxx://` 链接）时先弹确认框，确认后以普通权限打开；网页脚本自动唤起的直接拦截
- **数据目录可改**：「管理配置 → 数据目录」查看或更改设置、收藏、浏览记录和登录状态的保存位置（默认 `%LocalAppData%\GenshinBrowser`，设置记在注册表 `HKCU\Software\GenshinBrowser`，不依赖 AppData 里的文件）；换到空文件夹时可以把现有数据搬过去，重启后生效，旧位置的数据保留，确认无误后自己删除；设置的位置不可用（如移动硬盘没接）时本次退回默认位置并提示

### 本地日志
- **自动记录**：运行日志写入数据目录下的 `logs\`（默认 `%LocalAppData%\GenshinBrowser\logs\`）
- **异常追踪**：未处理异常自动捕获并写入日志
- **排查方便**：按日期归档，便于定位问题

### 控制窗口
- **独立面板**：主窗口专注显示内容，控制窗口提供地址栏、收藏、历史等操作
- **实时同步**：地址栏跟随浏览器 URL 变化
- **主题与语言**：暗色 / 亮色 / 跟随系统，中文 / English 界面
- **下载管理**：下载进度、取消、重试、打开文件与所在文件夹；本程序以管理员身份运行，打开文件时经资源管理器以普通权限打开，可执行文件、脚本、安装包等只在文件夹中定位

## 🖥️ 运行要求

- Windows 10/11 x64
- Edge WebView2 Runtime：标准版用系统里的（Windows 11 自带，缺了首次启动自动安装）；完整版内置固定版本，不需要
- .NET 8 Runtime：两种发布包都已内置，无需安装

## 📦 发布与使用

### 自动化测试
```powershell
dotnet test tests/GenshinBrowser.Tests/GenshinBrowser.Tests.csproj
```

### 发布包（两种，都已内置 .NET，开箱即用）
- 标准版 `GenshinBrowser-vX-win-x64.zip`：用系统里的 WebView2 运行时，体积小；首次启动自动检测并安装 WebView2 Runtime（如需）
- 完整版 `GenshinBrowser-vX-win-x64-full.zip`：`WebView2Runtime\` 里内置 WebView2 固定版本运行时（版本见 `release/webview2-fixed-runtime.json`），不依赖系统里的 WebView2，系统更新不会改变它的行为；体积大，安全补丁随本项目发版更新；不能放在网络共享路径上运行
- 本地发布：`./release/publish-win-x64.ps1 -Version v0.2.1`，加 `-BundleWebView2` 同时输出完整版
- 发布目录：`dist/win-x64-self-contained/`（标准版）、`dist/win-x64-full/`（完整版）
- GitHub Actions 仅支持手动触发（Actions → CI and Release）：可只跑构建/测试，或完整发布 win-x64；勾选 `bundle_webview2`（默认勾上）时同时生成完整版

### 升级内置的 WebView2 运行时
1. 在 [WebView2 下载页](https://developer.microsoft.com/microsoft-edge/webview2/) 的 Fixed Version 里取新版本 x64 .cab 的下载链接（官网只提供最近两个大版本）
2. 改 `release/webview2-fixed-runtime.json` 的 `version`、`url`，`sha256` 先留空
3. 运行 `./release/publish-win-x64.ps1 -BundleWebView2`：脚本下载后报 SHA-256 不符并给出实际值，填进 `sha256` 再运行一次；自检会校验运行时里的 exe 都是微软签名、版本号与配置一致
4. 用完整版实测视频播放、视频铺满、浮窗后再发版；只往新版本升，建议至少一两个月或微软发安全更新时升一次

### 快捷键
全局热键（默认值，可改键；生效范围见上文）：
- `K`：播放/暂停视频
- `F8`：切换 浏览 / 浮窗
- `F7`：隐藏/恢复窗口
- `;` / `'`：视频倒退 / 快进 5 秒

窗口内快捷键：
- `Ctrl` + `=` / `-` / `0`：页面放大 / 缩小 / 重置缩放
- `Ctrl` + `L`：聚焦控制台地址栏并全选

## 🔀 分支说明

- **`main`**：WPF + WebView2 主线版本（本分支）
- **`WinUI3-Experimental`**：WinUI 3 重构实验版，与主线共用 `%LocalAppData%\GenshinBrowser\settings.json`（主线改过数据目录后，实验版仍读这个默认位置），热键通过 `SchemaVersion`（1=WPF Key 枚举 / 2=Win32 虚拟键码）双向兼容。实验版只认识 浏览 ⇄ 浮窗 与 播放/暂停 两组热键：在实验版里保存过设置后，主线的隐藏、快进快退键、热键生效范围与鼠标穿透会回到默认值
