# Genshin Browser

一个专门为 B 站原神攻略视频设计的 Windows 浮窗浏览器，基于 `WPF + WebView2`。

## ✨ 功能

### 浮窗透明
- **透明度可调**：10%–100%，自由调节窗口透明度
- **游戏叠加使用**：半透明浮窗置于游戏上层，边玩边看
- **鼠标穿透（可选，默认关）**：开启后浮窗模式下点击直接落到下层游戏；浮窗内无法点击和拖动，按 `F8` 回浏览模式调整

### 窗口模式
- **浮窗**：窗口置顶，适合叠在游戏上观看
- **浏览**：可拖动、调整大小，配合控制台找片与设置
- **快捷键切换**：`F8` 一键切换 浏览 ⇄ 浮窗
- **临时隐藏**：`F7` 隐藏/恢复窗口，视频继续播放（保留声音），任务栏图标可点击恢复
- **浮窗提示**：浮窗模式下按热键播放/暂停、快进/倒退时，主窗底部显示短提示；页面没有视频或自动播放被拦截也会提示

### 自定义按键
- **五组热键**：浏览 ⇄ 浮窗、播放/暂停、隐藏窗口、倒退 5 秒、快进 5 秒，均可在「按键绑定」面板中修改
- **生效范围三档**：黑名单外（默认，在浏览器、聊天工具、编辑器等已知非游戏软件中不触发）/ 全部应用 / 关闭
- **防误触**：在页面或控制台输入框中打字时不触发播放与快进快退

### 浏览与记录
- **登录态保留**：Cookie、自动填充和已保存密码不会被缓存清理影响；缓存超过阈值时自动回收（只清可再生缓存，不动站点本地设置，如 B 站播放器音量、弹幕设置）
- **收藏夹**：一键收藏，支持搜索
- **浏览历史**：自动记录访问历史，支持搜索
- **地址栏联想**：输入时从收藏和浏览记录里给出候选（收藏在前），`↑` `↓` 选择、`Enter` 打开、`Esc` 关闭
- **智能恢复**：记住上次浏览的页面、窗口位置和大小

### 本地日志
- **自动记录**：运行日志写入 `%LocalAppData%\GenshinBrowser\logs\`
- **异常追踪**：未处理异常自动捕获并写入日志
- **排查方便**：按日期归档，便于定位问题

### 控制窗口
- **独立面板**：主窗口专注显示内容，控制窗口提供地址栏、收藏、历史等操作
- **实时同步**：地址栏跟随浏览器 URL 变化
- **主题与语言**：暗色 / 亮色 / 跟随系统，中文 / English 界面
- **下载管理**：下载进度、取消、重试、打开文件与所在文件夹

## 🖥️ 运行要求

- Windows 10/11
- Edge WebView2 Runtime（Windows 11 自带）
- .NET 8 Runtime（自包含版本无需安装）

## 📦 发布与使用

### 自动化测试
```powershell
dotnet test tests/GenshinBrowser.Tests/GenshinBrowser.Tests.csproj
```

### 自包含版本（推荐）
- 本地发布：`./release/publish-win-x64.ps1 -Version v0.2.1`
- 发布目录：`dist/win-x64-self-contained/`
- 无需安装 .NET，开箱即用
- 首次启动自动检测并安装 WebView2 Runtime（如需）
- GitHub Actions 仅支持手动触发（Actions → CI and Release）：可只跑构建/测试，或完整发布 win-x64

### 应用图标
- 源图：`Resources/AppIcon/keqing-sticker.png`（完整贴纸，用于 48px 及以上）与 `keqing-head.png`（头部特写，用于 40px 及以下和主窗标题栏）
- 换图后重新生成 `app.ico`：`./release/build-app-icon.ps1`

### 快捷键
全局热键（默认值，可改键；生效范围见上文）：
- `K`：播放/暂停视频
- `F8`：切换 浏览 / 浮窗
- `F7`：隐藏/恢复窗口
- `;` / `'`：视频倒退 / 快进 5 秒

窗口内快捷键：
- `Ctrl` + `=` / `-` / `0`：页面放大 / 缩小 / 重置缩放
- `Ctrl` + `L`：聚焦控制台地址栏并全选

## 🔀 分支说明

- **`main`**：WPF + WebView2 主线版本（本分支）
- **`WinUI3-Experimental`**：WinUI 3 重构实验版，与主线共用 `%LocalAppData%\GenshinBrowser\settings.json`，热键通过 `SchemaVersion`（1=WPF Key 枚举 / 2=Win32 虚拟键码）双向兼容。实验版只认识 浏览 ⇄ 浮窗 与 播放/暂停 两组热键：在实验版里保存过设置后，主线的隐藏、快进快退键、热键生效范围与鼠标穿透会回到默认值
