## 0. 需求边界

### 导出 / 导入的内容

| 内容 | 包含 |
|------|------|
| 窗口 | 主窗大小与位置、控制窗大小与位置 |
| 设置 | 不透明度、页面缩放、鼠标穿透、主题、语言 |
| 快捷键 | 五组热键（含修饰键）、热键生效范围 |
| 上次打开的页面 | 导出时的当前页面；导入后浏览器直接打开它（退出时上次页面会被当时的页面覆盖，所以只能导入时打开） |
| 收藏 | 全部（上限 100 条） |
| 浏览记录 | 全部（上限 200 条） |

### 不导出

| 内容 | 原因 |
|------|------|
| 登录状态、Cookie、已保存密码、站点数据（如 B 站播放器音量、弹幕设置） | 敏感；而且在 WebView 数据目录里，体积大。换机后重新登录即可 |
| 下载记录 | 存的是本机文件路径，换到别的电脑全是失效条目 |
| 当前窗口模式 | 临时状态：导入时一定在浏览模式（设置面板只在浏览模式可见），导入后切成浮窗会把控制台藏起来 |
| 内部标志（缓存检查时间、一次性迁移标志、首次浮窗引导是否看过） | 程序内部用，不属于用户设置 |

## 1. 现状结论（调研摘要）

- 数据在 `%LocalAppData%\GenshinBrowser` 下：`settings.json`、`history.json`、`favorites.json`、`downloads.json`。设置、收藏、历史在内存里各有一份，改动后防抖落盘；直接改文件会被内存里的数据覆盖回去，所以导入必须经过服务层。
- `SettingsService.Sanitize`（私有）已有整套清洗：坐标 / 尺寸范围、不透明度与缩放钳制、热键合法性与五组冲突消解、主题 / 语言归一，以及 schema 2（WinUI 存的虚拟键码）的转换。`FavoritesService` / `HistoryService` 各有私有 `SanitizeEntries`：网址归一去重、标题截断、时间归一、条数上限。
- 「恢复默认」通过现有属性 setter 即时生效（不透明度、鼠标穿透、生效范围、缩放），热键由 `RestoreDefaultHotkeys` 逐组设置，并先把会冲突的组泊到空闲键。导入可以复用同一条路径，不需要重启。
- 主窗尺寸「应用」走 `ApplyBrowserWindowSize`（含屏幕工作区钳制、标题栏高度换算）；控制窗走 `RestoreControlWindowBounds`（含钳制）。
- 「恢复默认」「清理缓存」都是一键执行加 Toast 提示，不弹确认框。

## 2. 设计方案

### 2.1 文件格式

单个 JSON 文件，可以用记事本打开查看：

```json
{
  "Format": "GenshinBrowser.Config",
  "Version": 1,
  "ExportedAt": "2026-10-24T02:30:00Z",
  "Settings": { "…": "与 settings.json 相同的结构" },
  "Favorites": [ { "Url": "…", "Title": "…", "SavedAt": "…" } ],
  "History": [ { "Url": "…", "Title": "…", "VisitedAt": "…" } ]
}
```

- 默认文件名 `GenshinBrowser-config-20261024-1030.json`。
- `Settings` 段沿用 `AppSettings` 结构（导入时可直接复用现有清洗和 schema 处理）；导出前把第 0 节「不导出」的字段清成默认值。

### 2.2 导出

- 设置面板点「导出…」，弹系统保存对话框，按 2.1 写文件（原子写入，先写临时文件再替换，中途失败不会留下半个文件）。
- Toast：「已导出：设置、收藏 N 条、浏览记录 M 条」。

### 2.3 导入

1. 设置面板点「导入…」，弹系统打开对话框（只显示 `*.json`）。
2. 校验（外部文件，按系统边界处理）：
   - 文件大小上限 24 MB（三份数据各自上限之和再留余量），超出直接拒绝、不读进内存；
   - `Format` 不对：提示「不是 Genshin Browser 的配置文件」；
   - `Version` 比当前程序新：提示「配置文件来自更新的版本，请先升级程序」；
   - JSON 损坏：提示「配置文件已损坏」；
   - 缺某一段时跳过该段（例如只有设置的文件也能导入）。
3. 导入前自动备份：先把当前配置按 2.1 写到数据目录 `backups\before-import.json`（每次覆盖），导入后不满意可以再导入这个文件撤回。
4. 所有值再过一遍现有清洗：设置走 `SettingsService` 的清洗，收藏 / 历史走各自的 `SanitizeEntries`。越界值被拉回范围，冲突热键按现有规则让位。
5. 即时生效，不重启：
   - 主题、语言、不透明度、缩放、鼠标穿透、生效范围：走现有 setter；
   - 热键：把 `RestoreDefaultHotkeys` 改成「按目标组合批量设置」，恢复默认与导入共用，逐组设置时不会互相顶掉；
   - 主窗大小走 `ApplyBrowserWindowSize`，位置设置后钳制到屏幕内；控制窗大小和位置走 `RestoreControlWindowBounds`。
6. 收藏 / 浏览记录与现有记录合并（第 5 节问题 1）：按网址去重，同一网址保留时间较新的一条，按时间倒序排列，超过上限截掉最旧的。导入完立即落盘，不等防抖。
7. 刷新控制窗的列表和设置面板文字。Toast：「已导入：设置、收藏 N 条、浏览记录 M 条；导入前的配置已备份」。

### 2.4 界面（已按你的意见改为右上角「管理配置」菜单，见第 6 节后续调整）

- 设置面板最后（语言下面）加一行：标签「配置文件」，右边两个按钮「导出…」「导入…」，跟其它行一样是标签列加控件。按钮带提示文字，说明导出哪些内容、不含登录状态。
- 只在浏览模式的控制窗里出现（浮窗时控制窗是隐藏的）。

1. **收藏 / 浏览记录的导入方式**：合并（推荐：不会丢现有记录，同一网址保留较新的；新电脑上导入时效果等同于完整恢复），还是覆盖成文件里的样子？

### 你的决定（2026-10-24）

1. 收藏 / 浏览记录：**有冲突时让用户选**合并、覆盖或取消。冲突指现有列表里有文件里没有的网址（覆盖会把它们替换掉）；没有冲突时两种结果相同，直接导入，不弹窗。收藏和浏览记录始终是两个独立列表，同一网址在两边都保留，规则各自生效。
2. 窗口位置：大小和位置都导入（按推荐）。
3. 导入前不弹确认框，先自动备份（按推荐）；上面的冲突对话框是唯一会弹的窗口。
4. 上次打开的页面也导入：导入后直接打开。
