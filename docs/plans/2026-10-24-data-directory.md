## 0. 需求边界

### 要做

| 编号 | 项 | 一句话 |
|------|----|--------|
| D1 | 数据目录指针 | 程序启动时先读「数据目录在哪」，不依赖 AppData 里的符号链接；没设置或设置的位置不可用时退回默认位置 |
| D2 | 程序内设置 | 「管理配置」菜单加「数据目录」：查看当前位置、打开文件夹、更改位置 |
| D3 | 更改位置时的数据 | 新位置已有本程序数据：直接切过去；没有：可以把现在的数据搬过去，或从空白开始 |
| D4 | 重启生效 | 浏览器内核运行时目录被占用，更改后自动重启程序生效 |
| D5 | 测试开关 | 环境变量 `GENSHINBROWSER_DATA_DIR` 临时指定目录（优先级最高），用于在 Claude 这边跑真程序测试 |

### 不做

- 不自动删除旧位置的数据：搬过去以后旧数据原样保留，提示你确认没问题后自己删。
- 不改你的 AppData 符号链接：要不要删由你决定（见第 4 节）。

## 1. 现状结论

- 数据目录在 4 处各自拼 `%LocalAppData%\GenshinBrowser`：`MainWindow` 构造（settings / history / favorites / downloads）、WebView2 用户数据目录（`WebViewProfile`，两处）、`FileLogger` 日志目录、`App` 启动时清理残留临时文件。
- `App.OnStartup` 用单实例互斥量：已有实例在运行时新进程直接退出。程序自己重启时新进程会撞上还没退干净的旧进程，必须先等它退出。
- 主窗由 `StartupUri` 在 `OnStartup` 之后创建，所以在 `OnStartup` 里决定数据目录、做数据搬运，都发生在任何文件被打开之前。

---

## 2. 设计方案

### 2.1 指针存在哪（D1）

推荐存注册表 `HKCU\Software\GenshinBrowser` 的 `DataDirectory` 值：

- 不在 AppData 留任何文件，符号链接可以删；
- 与程序放在哪个文件夹无关，换新版本（新的发布目录）照样能找到数据；
- 是 Windows 程序保存每用户设置的常规位置，本程序读系统主题时已经在读 HKCU。

另外两种做法的问题：放在 exe 旁边的配置文件，每次解压新版本到新文件夹都会丢；放在 AppData 的小文件，等于还是要在 C 盘 AppData 留一个文件夹。

启动时按优先级决定数据目录：环境变量 `GENSHINBROWSER_DATA_DIR` → 注册表 `DataDirectory` → 默认 `%LocalAppData%\GenshinBrowser`。设置的位置不存在或不能写（例如 D 盘没接上）时，本次退回默认位置，并在主窗提示「数据目录 X 不可用，本次使用默认位置」，注册表里的设置保留，下次 D 盘在时照常使用。

### 2.2 统一入口

- 新增 `Services/AppPaths.cs`：启动时解析一次，提供数据根目录、`WebViewProfile`、`logs` 路径；上面 4 处全部改用它。
- `FileLogger` 的测试覆盖开关不变。

### 2.3 程序内设置（D2、D3、D4）

「管理配置」菜单在「恢复默认」上方加「数据目录」（文件夹图标），点开窗内卡片：

- 标题「数据目录」，正文是当前路径；按钮：[更改位置]（主按钮） [打开文件夹] [取消]。
- 更改位置：弹系统选择文件夹对话框，选定后：
  - 新位置里已有本程序的数据（有 settings.json）：卡片「这里已有 Genshin Browser 的数据，要切换过去吗？」[切换] [取消]
  - 没有：卡片「要把现在的数据搬过去吗？」[搬过去]（主按钮） [从空白开始] [取消]
  - 选的就是当前目录、或者不能写入：直接提示原因，不改设置。
- 确认后写注册表，弹卡片「重启后生效」[立即重启] [稍后]。选稍后则下次启动生效。

### 2.4 重启与搬运

- 立即重启：用 `--wait-for-previous` 参数启动新进程，旧进程正常关闭（照常把数据存进旧位置）。新进程带这个参数时等旧进程释放单实例互斥量（最多 30 秒），而不是直接退出。
- 需要搬运时，注册表同时记 `PendingMoveFrom`（旧位置）。新进程在 `OnStartup` 里、主窗创建之前复制：设置、收藏、浏览记录、下载记录、日志、浏览器数据（登录状态、Cookie），显示一个小进度窗。全部复制成功才清掉 `PendingMoveFrom` 并启用新位置；复制失败时本次继续用旧位置并提示原因，什么都不丢。
- 旧位置的数据不删除；搬完提示「旧位置的数据还在 X，确认无误后可以自己删除」。

## 4. 你的机器上怎么切过去

1. 新版本里打开「管理配置 → 数据目录 → 更改位置」，选 `D:\mklink_download\local-genshinbrowser\GenshinBrowser`。那里已有数据，选「切换」并重启，不需要搬运。
2. 用一段时间确认一切正常后，符号链接就用不上了，可以删掉。删的时候只删链接、不要删里面的内容：在 cmd 里运行 `rmdir "%LOCALAPPDATA%\GenshinBrowser"`（不要加 `/s`），或在资源管理器里删这个链接图标。

## 6. 实施记录（2026-10-24）

你的决定：三项都按推荐——指针存注册表；改到空目录时可选「搬过去 / 从空白开始」；改完问是否立即重启（可选稍后）。

实现与计划的差别：

- 菜单里「数据目录」（文件夹图标 E8B7）放在「导出配置」之后、分隔线和「恢复默认」之前。
- 当前位置卡片的按钮是 [更改位置] [打开文件夹] [关闭]：窗内询问卡片的取消按钮可以换文字（这里是「关闭」，重启卡片是「稍后」）。
- 待搬运标记在复制成功后才清掉：复制中途程序崩溃时，下次启动会重新复制（同名覆盖）；复制失败时本次与之后都退回旧位置并提示原因。新位置这次不可用（比如盘没接上）时标记保留，等可用时再搬。

- 搬运时跳过符号链接和联接点，避免复制到链接指向的别处。
